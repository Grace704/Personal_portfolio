Design and build a polished personal portfolio website for **Grace**. The website should feel futuristic, elegant, creative, and slightly cinematic while still being clean and easy to navigate.

## Overall Visual Direction

Use a **dark, atmospheric background** with a color palette built around:

* Deep navy / midnight blue
* Purple
* Dark pink / magenta
* Subtle violet
* Near-black backgrounds
* White or slightly purple-tinted text

Use gradients carefully, especially combinations of deep blue → purple → dark pink. Avoid making every element glow. The site should feel sophisticated rather than like a generic neon cyberpunk website.

Use large typography, generous spacing, subtle glass effects, soft blurred light sources, and occasional thin glowing borders.

Avoid the stereotypical AI-generated website appearance:

* No excessive rounded cards
* No gradient on every piece of text
* No giant collection of identical rectangular sections
* No excessive glassmorphism
* No random glowing buttons everywhere
* No cluttered dashboard-style layouts

Create visual variety between sections.

## Animated Background

The website should feel alive even when the user isn't interacting with it.

Create a subtle animated background across the site. Instead of normal snowflakes, use small abstract glowing particles, tiny stars, petals, or soft geometric fragments that slowly drift downward and sideways.

Particles should use very subtle purple, blue, and pink tones with different sizes, speeds, opacity, and depth.

Some particles should appear blurred and closer to the viewer while others are small and distant to create depth.

Add subtle mouse parallax so background elements move slightly based on cursor position.

Animations must remain slow and elegant. They should never distract from the content.

## Navigation

Create a minimal floating/sticky navigation bar.

Include:

Home
About Me
Experience
Projects
Skills
Competitions
Education
Hobbies

The navigation should indicate the active section. Add smooth scrolling and subtle hover animations.

On smaller screens, convert this into a clean mobile menu.

## Hero Section

Make the opening screen visually impressive but minimal.

Large headline:

"Hi, I'm Grace."

Below it, add a short placeholder introduction that Grace can customize later.

Include a short rotating or animated text line for roles/interests, such as:

Designer • Developer • Creator

Treat these as placeholders rather than assuming Grace's actual roles.

Add two main actions:

"Explore My Work"
"About Me"

Create a futuristic visual element around or behind the hero. Consider an abstract glowing orb, flowing gradient mesh, constellation, particle field, or interactive 3D-inspired shape.

The hero should occupy most of the first viewport.

## About Me

Create an editorial-style About section rather than putting everything inside a card.

Include space for:

* Portrait/photo
* Short biography
* Current focus
* Interests
* Location if Grace chooses to include it
* A few personal facts

Use an asymmetrical layout with the image on one side and typography on the other.

## Experience

Create a vertical interactive timeline.

Each experience should contain:

Role
Organization
Dates
Short description
Technologies/skills used

When hovering over an experience, subtly illuminate its timeline node and content.

## Projects

Projects should be one of the strongest visual sections.

Create a responsive project showcase with large project previews rather than small identical cards.

Each project can include:

Project image/mockup
Project name
Short description
Technologies
GitHub link
Live demo link

Allow featured projects to occupy more space than smaller projects.

On hover, slightly move or tilt the project preview and reveal additional information.

Add filtering such as:

All / Web / Data / AI / Design / Other

These categories should be easy to customize later.

## Skills

Don't make this just a wall of progress bars.

Organize skills into categories such as:

Languages
Frameworks
Tools
Design
Data / AI

Use clean icons, typography, and subtle interactive effects.

Consider a constellation/network visualization where related skills are visually connected, while still providing a normal accessible list underneath or on mobile.

## Competitions

Create a section for competitions, hackathons, awards, tournaments, or other achievements.

Use a timeline or horizontal showcase.

Each entry should support:

Competition name
Year
Result/placement
Description
Photo or logo
Related project/link

Make major achievements visually larger without making the section look like an awards ceremony.

## Education

Create a clean education timeline.

Include:

School / university
Program
Years
Relevant coursework
Activities
Awards if applicable

Use subtle connecting lines and purple/pink accents.

## Hobbies

Make this section more personal and visually different from the professional sections.

Use an image-driven layout for hobbies and interests.

Images can expand slightly on hover and reveal a short caption or story.

Leave room for hobbies such as sports, travel, photography, music, art, gaming, cooking, or anything Grace wants to add.

## Footer / Contact

End with a strong but simple contact section.

Large text:

"Let's connect."

Include placeholders for:

Email
LinkedIn
GitHub
Instagram or other social links

Add a small animated visual in the background that responds subtly to cursor movement.

## Interaction Details

Throughout the website, add:

* Smooth scrolling
* Scroll-triggered entrance animations
* Subtle parallax
* Animated navigation indicator
* Gentle text reveals
* Project hover interactions
* Cursor-responsive background particles
* Smooth page/section transitions
* Subtle button animations

Animations should use smooth easing and should feel restrained rather than flashy.

Respect `prefers-reduced-motion` for accessibility.

## Technical / Responsive Design

Design desktop first but make the entire website responsive for tablet and mobile.

Maintain strong contrast and readable typography.

Use reusable components and a consistent spacing system.

Keep performance in mind. Background animation should not cause lag or interfere with scrolling.

The final result should feel like a custom-designed portfolio for Grace rather than a portfolio template. Prioritize typography, spacing, motion, depth, and visual hierarchy over adding more UI elements.
